## Theme structure: three color levels

1. **Root fields** (`background`, `foreground`, `tableAccent`, ...) — base colors.
   The schema supports **31 named semantic names** (`background`,
   `foregroundNeutralDark`, `good`, `bad`, `hyperlink`, `selection`, `separator`, etc.),
   but the project's actual theme defines only 3 (`background`, `foreground`, `tableAccent`) —
   Power BI computes the other 28 automatically (lightening/darkening of the base ones).
2. **`dataColors`** — a flat array of the palette's categorical colors (in the project — **480**
   HEX values: a base set of ~8-25 colors + shades auto-generated by Power BI,
   hard-coded statically in the file instead of being computed on the fly).
   ⚠️ **Corrected 2026-10-16:** `ThemeDataColor.ColorId` is **not** a plain index into this
   array: `ColorId 0` = `background`, `1` = `foreground` (text), **`2…` = `dataColors[ColorId − 2]`**
   (the color-picker row: white, black, then the palette). Proof (Collector Assignment): `ColorId 1`
   is used ~450× as the text color and renders dark, not as `dataColors[1]` (orange).
   ⚠️ **Only `ColorId` 0–9 resolve** (background, foreground, `dataColors[0…7]` = the picker row). A 9th+ color
   (`ColorId 10`) is kept in the theme but renders as a light fallback (ClientB icons 2026-10-30) — for an extra fixed
   color use a color measure (`_Measures`, folder `Color`, e.g. `'Blue Logo' = "#134591"`) bound with fx.
   **IBCS total in a matrix (ClientB 2026-10-30):** no fill — `rowTotal.backColor` = the rows' color (`#FDFCFA` in
   `Warm`), `bold` true. A line **above** the total is not possible: `pivotTable` has no total border, and
   `values` / `rowHeaders.outlineStyle` (bottom) has no visible effect (tested `1D` and `1L`).
   **The order of `dataColors` = the default series colors** (legend / multi-series charts) —
   similar colors must not be neighbours. To reorder, use
   `Scripts\ReorderThemeColors.ps1` (`PBIP_Scripts.md`): it also renumbers every
   `ColorId ≥ 2` so fixed palette references keep their colors.
   Collector Assignment / `ThemeWarm` 2026-10-16: red · orange · yellow · teal · blue · navy ·
   purple · magenta → red · teal · yellow · purple · orange · blue · magenta · navy (46
   references renumbered: `5→3` ×44, `7→9` ×2) → same day, user: "I don't like red and green
   near each other, switch blue and green" → **final: red · blue · yellow · purple · orange ·
   teal · magenta · navy** (`#C0392B #0087B6 #F7BE0F #6A4C93 #E85423 #099078 #B84A9C #01238E`;

   reordered the same way.
3. **`visualStyles`** — format settings per visual type (see below).
